## 二、核心知识

### 1. 四种操作

| 操作 | 示例 | 调用函数 |
|---|---|---|
| 拷贝构造 | `Student b = a;` | 拷贝构造函数 |
| 移动构造 | `Student c = std::move(a);` | 移动构造函数 |
| 拷贝赋值 | `d = b;` | 拷贝赋值运算符 |
| 移动赋值 | `d = std::move(b);` | 移动赋值运算符 |

构造操作用于初始化新对象，赋值操作用于修改已经存在的对象。

### 2. std::move

`std::move` 定义在 `<utility>` 中，本身不直接搬运资源，而是将表达式转换为能够参与右值引用重载匹配的形式。

实际资源转移由被调用的移动构造函数或移动赋值运算符完成。

### 3. 移动构造

移动构造函数的典型实现：

    Student(Student&& other) noexcept
        : name(std::move(other.name))
    {
        std::cout << "Move Constructor\n";
    }

移动构造用于初始化新对象。初始化列表直接初始化成员，避免先默认构造再赋值。

### 4. 移动赋值

移动赋值运算符的典型实现：

    Student& operator=(Student&& other) noexcept
    {
        if (this == &other)
            return *this;

        name = std::move(other.name);

        std::cout << "Move Assignment\n";
        return *this;
    }

移动赋值用于将资源转移到已经存在的对象。

赋值运算符通常返回 `Student&`，避免按值返回造成不必要的对象复制，并支持连续赋值。

### 5. 移动后的对象

移动后的对象仍然是有效对象，可以继续析构或重新赋值。

对于 `std::string`，移动后的状态有效但未指定。不能将“移动后字符串一定为空”当作通用规则。

### 6. 对象生命周期

局部对象离开作用域时自动析构。同一作用域中的局部对象通常按照构造顺序的逆序析构。
