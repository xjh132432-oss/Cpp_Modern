# Cpp_Modern

C++ Modern 特性学习与实践仓库。

本仓库用于在完成 C++ 工程化基础后，继续学习现代 C++ 中常用的语言特性，
采用“干中学”的方式，通过实际代码理解语法、行为和工程使用场景。

## 学习目标

- 理解 `const` 的基本作用
- 理解 C++ 引用
- 理解 `const` 引用
- 理解值传递、引用传递的区别
- 理解 `T`、`T&`、`const T&` 作为函数参数时的区别
- 理解 `const T&` 为什么可以绑定临时对象
- 建立现代 C++ 函数接口设计的基础认识

## 学习方式

每个阶段以实际问题和代码为主：

1. 先自己实现
2. 判断代码行为
3. 分析原因
4. 总结语言规则
5. 在实际代码中使用
