# Day03 Workflow - shared_ptr

## 今日任务

学习并实践 C++ `std::shared_ptr`，验证共享所有权、引用计数和对象生命周期。

## 实际完成

### 1. 创建共享智能指针

使用 `std::make_shared<Student>()` 创建对象，并通过 `->` 访问成员。

### 2. 验证引用计数

创建第二个 `shared_ptr` 指向同一对象，观察 `use_count()` 从 `1` 变为 `2`。

当第二个智能指针离开作用域后，引用计数恢复为 `1`。

### 3. 验证共享对象

通过其中一个智能指针修改对象的 `name`，再通过另一个智能指针读取，确认两者访问的是同一个对象。

### 4. 验证函数参数传递

将 `shared_ptr<Student>` 按值传入 `printStudent()`。

观察函数执行期间引用计数增加，函数返回后引用计数恢复。

### 5. 验证对象自动销毁

通过 `Student` 的析构函数输出确认：最后一个共享所有者释放后，对象才被销毁。

## 本日结论

- 掌握 `std::make_shared` 的基本使用。
- 理解 `use_count()` 的含义。
- 理解多个 `shared_ptr` 共享同一对象。
- 理解作用域、函数参数与共享所有权之间的关系。
- 理解 `shared_ptr` 与 `unique_ptr` 的主要区别。
