# Day04 Workflow - weak_ptr

## 今日任务

学习并实践 C++ `std::weak_ptr`，理解弱引用、共享引用计数与对象生命周期之间的关系。

## 实际完成内容

### 1. 创建弱引用

使用 `std::weak_ptr<Student>` 观察由 `std::shared_ptr<Student>` 管理的对象。

### 2. 验证引用计数

通过 `use_count()` 观察共享引用计数，理解创建 `weak_ptr` 不会增加共享所有者数量。

### 3. 使用 lock()

通过 `weak.lock()` 获取 `shared_ptr`，并判断返回值是否有效，再访问对象成员。

### 4. 使用 expired()

通过 `weak.expired()` 检查弱引用对应的对象是否仍然存在。

### 5. 理解对象销毁

结合作用域与 `Student` 析构函数的输出，分析最后一个 `shared_ptr` 释放后对象的销毁时机。

## 本日总结

- 掌握 `weak_ptr` 的基本声明与使用。
- 理解 `lock()` 返回共享智能指针的机制。
- 理解 `expired()` 的用途。
- 理解弱引用不会延长对象的共享所有权生命周期。
- 初步理解 `weak_ptr` 与避免循环引用的关系。
