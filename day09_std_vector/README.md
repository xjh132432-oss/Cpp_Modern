# Day09 — std::vector

## 学习目标

掌握 C++ 标准库容器 `std::vector` 的基本使用，理解动态数组的容量管理、元素插入、迭代器遍历，以及 `vector` 与复制构造、移动构造之间的关系。

## 核心知识

### 1. std::vector 基础

- `std::vector<Student>`：创建存储 `Student` 对象的动态数组。
- `size()`：获取当前元素数量。
- `capacity()`：获取当前容量。
- `begin()`、`end()`：获取首元素迭代器和尾后迭代器。
- 使用迭代器遍历元素，访问学生姓名和分数。

### 2. 元素插入

- `emplace_back()`：在容器尾部直接构造元素。
- `push_back()`：将已有对象复制或移动到容器尾部。
- `std::move()`：将表达式转换为右值，允许移动构造等操作参与重载决议；它本身不执行移动。

### 3. 容量管理

- `reserve(n)`：在当前容量不足时，预留至少能容纳 `n` 个元素的存储空间。
- `reserve()` 不会创建元素，也不会改变 `size()`。
- 当插入元素导致容量不足时，`vector` 可能重新分配存储空间，并搬迁已有元素。
- 容量变化策略由标准库实现决定，不应假定每次扩容的具体数值。

### 4. 对象生命周期与移动语义

通过 `Student` 类中的构造、复制构造、移动构造和析构日志，观察不同插入方式的行为，并比较调用 `reserve()` 前后的元素搬迁情况。

### 5. 数据统计

遍历容器，完成以下功能：

- 输出每位学生的姓名和分数。
- 计算平均分。
- 找出最高分及对应学生。

## 实践内容

- 使用 `std::vector<Student>` 管理学生对象。
- 使用 `emplace_back()` 插入 Alice。
- 使用 `push_back()` 复制插入 Bob。
- 使用 `push_back(std::move(cha))` 移动插入 Charlie。
- 比较预留容量与未预留容量时的构造和移动日志。
- 输出容器的 `size()`、`capacity()`、学生信息、平均分和最高分。
