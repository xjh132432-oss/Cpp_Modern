# Day10 Pitfalls — Iterator Invalidation

## 实际遇到的问题：解引用失效迭代器

在实验二中，先保存迭代器 `it`，再调用 `reserve(capacity() + 1)` 触发内存重新分配，随后继续执行 `std::cout << *it`。

程序输出了 `10`，随后输出 `0`，没有立即报错。

### 原因

`reserve()` 触发重新分配后，原迭代器 `it` 已经失效。继续解引用它属于未定义行为，因此输出结果没有可靠意义，不能据此判断旧迭代器仍然有效。

### 正确做法

重新分配后，不再解引用旧迭代器；需要访问元素时，重新获取 `begin()` 等有效迭代器。
